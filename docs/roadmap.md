# Roadmap

Bienvenue sur la nouvelle version de **The French Apple Wiki**, désormais hébergée sur **GitHub Pages** en Markdown (zéro base de données à perdre !).

## Comment contribuer / éditer une page

1. Ouvre n'importe quelle page du wiki.
2. Clique sur **« Modifier cette page sur GitHub »** en bas de l'article.
3. Modifie le texte en Markdown et enregistre (commit sur `main` ou Pull Request).
4. Le site se met à jour automatiquement en ~30 secondes via GitHub Actions.
