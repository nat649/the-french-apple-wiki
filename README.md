# The French Apple Wiki

Site en ligne : **https://nat649.github.io/the-french-apple-wiki/**

Wiki francophone dédié à l'univers Apple (appareils, systèmes d'exploitation, histoire, jailbreak et Apple Internals), propulsé par [VitePress](https://vitepress.dev/) et hébergé gratuitement sur **GitHub Pages**.

## Modifier ou ajouter un article

- **Directement sur GitHub :** ouvre un fichier dans `docs/` (ou clique sur *« Modifier cette page sur GitHub »* en bas de n'importe quelle page du site).
- **En local :**
  ```bash
  npm install
  npm run docs:dev
  ```
- Chaque push sur `main` reconstruit et déploie automatiquement le site via GitHub Actions.
